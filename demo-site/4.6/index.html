Components demo

Every component of the framework on a page of its own, ready to test.

The pages of version 4.6 of the components (4.6 has no offcanvas). Each page shows a set of components with the markup of the documentation and the examples, adapted for testing: every component has a name a person can read, and a few small scripts stand in for what a site would do (a list that loads, an upload, the answer to a form).
